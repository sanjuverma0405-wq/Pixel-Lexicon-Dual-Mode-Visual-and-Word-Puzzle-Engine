# Pixel-Lexicon-Dual-Mode-Visual-and-Word-Puzzle-Engine
Pixel &amp; Lexicon is a whimsical desktop puzzle sanctuary featuring a 15-puzzle and a 4x4 word builder. Crafted with a Python Tkinter GUI and a C++ backend, it showcases algorithmic integrations including A* Search, Merge Sort solvability verification, and Trie-based DFS pruning.
